# TaskTalker – Smart Task Manager using C

TaskTalker is a Smart Task Manager application built from scratch using **C programming** and **Data Structures**, with a custom HTTP server and a modern web-based user interface.
This project shows how low-level backend programming in C can be connected with frontend technologies like HTML, CSS, and JavaScript to build a complete application.

## Features
- Create tasks with:
  - Task name
  - Description
  - Due date and time
  - Priority (Low / Medium / High)
- Edit existing tasks
- Delete tasks
- Search tasks by name or description
- Automatic priority update based on due date
- Dark / Light theme toggle
- REST-style backend API
- Custom HTTP server written in C
- Clean and modern UI (no frameworks)

## Concepts Used
- Linked List (for dynamic task storage)
- Socket Programming (Winsock)
- HTTP protocol basics
- REST API design (GET, POST, PUT, DELETE)
- JSON data handling
- Time and date handling in C
- Frontend–Backend communication

## Technologies Used
- Language used : C
- Compiler: GCC (MinGW)
- Networking: Winsock (Windows)
- Frontend: HTML, CSS, JavaScript
